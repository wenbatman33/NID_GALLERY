# NID GALLERY 動態復刻

中村勇吾（yugop / tha ltd.）2007 年 Flash 作品〈NID GALLERY〉的動態研究。依 YouTube 影片逐幀量測後，以 Canvas 2D 與 Web Audio 重建。所有人物、作品、圖片、文字皆為虛構的假資料，人物肖像由 AI 生成，不是真人。

雙擊 `index.html` 即可執行，不需安裝或伺服器。

## 操作

| 操作 | 動作 |
|---|---|
| 滑鼠移到左／右 | 該側圓環放大為主動，另一側縮小 |
| 滾輪（方向鍵） | 旋轉主動圓環，轉過一格才出聲；停手後吸附並讓另一環轉到配對項目。沒轉過一格就彈回原位，不出聲 |
| 點縮圖 | 選定該項，另一環轉到配對項目（雙向） |
| 點選定的組合或叉號（Enter） | 開啟詳情 |
| 詳情中點面板 | 手動切換人物／作品（滑鼠停在面板上時暫停自動切換） |
| 詳情中點弧上縮圖 | 直接切換到該項 |
| 點叉號（Esc） | 關閉詳情 |
| M | 開關聲音 |
| D 或右下角齒輪 | DEV 微調工具 |

## 量測到的數值

- 版面（800×600）：圓心距中線 370；中性半徑 298；主動 408、被動 188（兩環半徑和恆為 596）；每環 28 項；選定放大 1.9 倍。
- 詳情：其餘 27 項均分到軸線上下各留空 45° 的 270° 弧上。
- 音效：單聲道、無背景音樂，全為正弦純音，頻率為 500／1000／2000／4000 Hz。

| 音效 | 組成 | 觸發時機 |
|---|---|---|
| 開啟 | 1 kHz 105 ms，起音後 140 ms 接 500 Hz 305 ms | 進場、開啟、關閉 |
| 載入 click | 500 Hz 約 20 ms 快速衰減，約每 92 ms 一響 | 縮圖載入 |
| 滾輪 | 單顆 55 ms，500／1k／2k 擇一 | 環實際轉過一格 |
| 三連音（下行） | 2k→1k→500，每顆 55 ms、間隔 90 ms | 選定、詳情切回人物 |
| 三連音（上行） | 500→1k→2k | 詳情切到作品 |
| 完成雙響 | 4 kHz 45 ms 兩聲，間隔 70 ms | X 長出時、內容載入完成 |

## 配對完成的動態

選定和關閉詳情回到配對時都走同一段，只作用在選定的兩張。

| 時間 | 畫面 |
|---|---|
| 0 秒 | 兩張圖瞬間全白，線框變亮白 |
| 0～0.13 秒 | 兩張圖之間出現一對互指的白三角，並縮小 |
| 0.13～0.3 秒 | 小三角往中點靠攏，併成白點 |
| 0.2～0.3 秒 | 全白淡出，圖與線框恢復原狀 |
| 0.3～0.44 秒 | 白點長成白 X，略微過衝回彈，同時響完成雙響 |
| 0.5～0.68 秒 | X 由白轉紅 |

## 檔案

- `js/config.js`：所有版面與節奏數值（PC／TABLET／MOBILE）
- `js/data.js`：28 人＋28 件作品的假資料與配對
- `js/imagery.js`：讀取人物照片，並程序化產生作品圖
- `js/audio.js`：Web Audio 音效
- `js/gallery.js`：主引擎
- `js/dev.js`：DEV 微調工具
- `assets/portraits/`：人物照片（512×512 JPG），`src/` 內是 1024×1024 原圖
- `scripts/portrait_manifest.json`：每位人物的肖像 prompt
- `scripts/gen_portraits.mjs`：透過 `codex exec` 批次生成肖像

## 更換肖像

直接用同檔名覆蓋 `assets/portraits/<id>.jpg` 即可，`id` 是 `p0`～`p27`，對應 `js/data.js` 的人物順序。檔案不存在時，該人物會退回程序化肖像。

要重新生成某一張：把 `assets/portraits/src/<id>.png` 和 `assets/portraits/<id>.jpg` 搬到別處，修改 manifest 的 prompt，再執行：

```bash
node scripts/gen_portraits.mjs --only p3
```

## 微調流程

按 `D` 開啟工具，拖滑桿或直接拖畫面上的虛線框，按「💾 匯出 / 鎖定」取得 JSON，貼回給 Claude 寫進 `js/config.js`。
